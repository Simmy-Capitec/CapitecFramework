# 🐾 Animal Sanctuary Management System - Capstone Project

## Project Overview

Welcome to the **Animal Sanctuary Management System Capstone Project** - the culminating experience for transitioning from manual testing to automated testing expertise. This comprehensive project challenges you to demonstrate mastery across three critical automation layers: SQL database testing, API automation, and frontend UI automation.

## 🎯 Project Mission

You are the Lead Test Automation Engineer for "Happy Paws Animal Sanctuary," a growing organization that needs a robust testing framework to ensure their management system operates flawlessly. Your mission is to create a comprehensive automated testing suite that validates:

- **Database integrity** through SQL testing
- **API functionality** through backend automation
- **User experience** through frontend automation

## 🏗️ System Architecture

### Technology Stack
- **Frontend**: Next.js 14 with TypeScript, Tailwind CSS, and Shadcn/UI
- **Backend API**: Node.js with Express.js
- **Database**: PostgreSQL with Drizzle ORM (`animal_sanctuary_capstone`)
- **Testing Frameworks**: Playwright for UI/API testing, Jest for unit testing
- **Automation Tools**: Playwright Test Runner, Drizzle for database operations, custom SQL testing utilities

### System Components
1. **Database Layer**: Animal, adopter, application, and volunteer data management
2. **API Layer**: RESTful endpoints for CRUD operations
3. **Frontend Layer**: React-based user interface for sanctuary management
4. **Testing Layer**: Comprehensive automation across all layers

## 📋 Project Scope

### Core Functionality to Test
- **Animal Management**: Add, update, view, and manage animal records
- **Adoption Process**: Handle adoption applications and approvals
- **Volunteer Coordination**: Manage volunteer schedules and activities
- **Donation Tracking**: Process and track monetary donations
- **Reporting**: Generate insights and statistics
- **User Authentication**: Secure login and role-based access

### Testing Requirements
- **Database Testing**: Data integrity, constraints, relationships
- **API Testing**: Endpoint validation, error handling, data flow
- **UI Testing**: User workflows, form validation, responsive design
- **Integration Testing**: End-to-end process validation
- **Performance Testing**: Load testing and response time validation
